# Как использовались ИИ-агенты

Проект делался с помощью Claude Code. Роли такие:

- Sonnet 5.5: разбор требований, архитектура и контракт (`ARCHITECTURE.md`), ревью, запуск тестов, правки найденных проблем.
- Haiku: исполнители, по одному на область (ядро backend, роутеры, ИИ и админка, фронтенд, лендинг, DevOps, дизайн-проход).

Файлы:

- `01-planning.md`: как поделили работу и какие решения приняли до кода
- `02-development.md`: что поручали агентам и что получилось
- `03-review.md`: что нашёл ревью и как исправили, что не проверено
- `04-ui-audit.md`: аудит интерфейса по web-interface-guidelines
