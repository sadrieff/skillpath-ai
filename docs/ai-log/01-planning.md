# Планирование

Исходные материалы: PDF с требованиями проектной работы, черновик плана платформы (SkillPath AI) и моё резюме.

## Что взято из требований

Вход через Google OAuth2, внешний AI API, загрузка файлов, поиск и фильтры, минимум три связанные таблицы, шесть экранов, адаптивная вёрстка, CRUD API, деплой, CI/CD, README и документация по использованию ИИ.

## Что решили

- Backend на Python (FastAPI), потому что это основной стек в резюме. PostgreSQL вместо SQLite добавляет в резюме то, чего там нет. Для тестов используется SQLite.
- Фронтенд на Next.js + TypeScript: тоже пробел в резюме.
- ИИ-наставник ходит в RouterAI, модель `qwen/qwen3.5-flash-02-23` (дешёвая, уже использовалась в другом моём проекте). Ключ только на сервере.
- Сначала контракт, потом код: `ARCHITECTURE.md` с таблицами, REST-эндпоинтами и страницами, плюс готовый `models.py`. Все исполнители работали по нему и не меняли его молча.

## Какие пробелы закрывает проект

| Пробел в резюме | Что в проекте |
|---|---|
| Нет публичного кода | открытый репозиторий |
| Нет frontend | Next.js, TypeScript, Tailwind |
| Только SQLite | PostgreSQL, миграции Alembic |
| Нет веб-авторизации | Google OAuth2, JWT, роли |
| Нет CI/CD | GitHub Actions |
| Нет облачного деплоя | Docker Compose, деплой на VPS |
